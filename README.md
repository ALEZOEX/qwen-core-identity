# QWEN CORE IDENTITY v20.0 (Final Production Edition)

[Read in English](README.en.md)

Мастер-промпт корпоративного уровня для преобразования LLM в автономные когнитивные системы с жесткими гарантиями качества, безопасности и управления контекстом.

## 🎯 Ключевые особенности

### 1. Модульная архитектура (Core + Extensions)
- **Core Rules**: Базовые правила для всех задач (иерархия приоритетов, классификация, Quick Path)
- **Extensions**: Опциональные модули для специфичных доменов (физика, инженерия, образование)

### 2. Quick Path для 80% запросов
Простые задачи без неопределенности и безопасности → прямой ответ БЕЗ анализа. Экономия токенов и времени.

### 3. Физические режимы
- **Physics Mode**: Качественные объяснения с аналогиями + расчеты с проверкой размерностей
- **Hypothetical Physics Mode**: Мысленные эксперименты ("Что если...") без поиска источников
- **Physics Education Mode**: Обучение через аналогии, минимум формул
- **Engineering Calculations Mode**: Обязательный запас прочности, учет нормативов

### 4. Robust BIO Tracking
- Именованные поля для робастного парсинга: `entity:X|status:unverified|role:Y|mentions:N`
- Молчаливая регистрация сущностей без навязчивых вопросов
- Time-based Garbage Collection (180 дней для `unverified`)
- Прозрачность: `[BIO] Добавлено: entity`

### 5. Domain-Specific Red Teaming
Адаптивные угрозы по доменам: Web, System, DevOps, ML, Blockchain, Physics/Engineering

### 6. No Self-Review Loop
Все проверки и исправления — ВНУТРИ `[АНАЛИЗ]`. В финал — только чистое решение.

### 7. 9-пунктовый чеклист
Механический самоконтроль перед выдачей первого токена.

## 📊 Классификация задач

| Тип | Описание | Протокол |
|-----|----------|----------|
| **[Простая]** | 1 домен, факт | Quick Path (прямой ответ) |
| **[Средняя]** | 2 домена | Анализ + ответ |
| **[Сложная-Имплементация]** | Код до 100 строк | Упрощенный `[АНАЛИЗ]` + решение |
| **[Сложная-Архитектура]** | Проектирование, HighLoad | ПОЛНЫЙ 6-фазный MoE |
| **[Критическая]** | Безопасность, медицина, финансы | `[CRITICAL WARNING]` + [Сложная] |

## 🚀 Быстрый старт

1. Скопируйте `QWEN_CORE_IDENTITY_v20.0.md` в системный промпт вашей LLM
2. Настройте оркестратор для поддержки инструментов `bio`, `web_search`, `history_retriever`
3. Используйте в production-средах с высокими требованиями к точности
